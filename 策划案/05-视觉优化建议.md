# 05 · 视觉优化建议（"太素"诊断与升级记录）

> 触发：2026-11-27 评审意见「再根据现有方案分析一下可优化点，感觉还是太素了」。
> 本文记录诊断结论、本轮已落地的改动、以及剩余必须靠素材才能解决的差距。

---

## 一、为什么"素"：四条根因

| # | 根因 | 具体表现 | 处理方向 |
|---|------|----------|----------|
| 1 | 全站 0 张实景图 | 9 个板块都是"文字 + 细边框白卡"，没有一张厂房、管道、施工现场 | 影像系统：占位框 + 拍摄清单，拿到图直接替换 |
| 2 | 明暗节奏单一 | 9 段里 7 段是白/浅灰底，页面像一张长表格 | 深浅交替：深绿通栏带、红色 CTA 带 |
| 3 | 层级扁平 | 所有区块标题 25px、所有卡片同重量、数字没有重量差 | 字号阶梯（32/50、24/36、16、13）、DIN 数字、材质色条 |
| 4 | 缺"现场感" | 没有工厂、设备、检测、施工中的画面语言 | 工厂与装备段、案例封面、内页图位 |

工业品官网的可信度，一半来自"参数说得清"，另一半来自"看得见你在生产"。前者我们已经做到（规格矩阵 + 剖面图），后者目前是空的——这就是"素"的来源。

## 三、还需要什么才能真正"不素"（卡在素材）

以下不是代码问题，是**必须企业提供**的物料。图位已经在页面里标好名称和拍摄建议。

| 优先级 | 素材 | 用在 | 拍摄建议 |
|--------|------|------|----------|
| P0 | 厂区大门/厂房全景 ×2 | 首页③、关于页 | 晴天上午顺光，横构图 1600×1200 以上 |
| P0 | 挤出生产线 ×3（含操作台） | 首页③⑤、关于页 | 带人在操作更有现场感，避免逆光 |
| P0 | 成品堆场/仓库 ×2 | 首页⑤ | 体现"常规口径备货" |
| P0 | 检测设备 ×2（静液压、环刚度） | 首页⑤、品质页 | 仪器特写 + 人操作 |
| P1 | 各系列产品白底图 ×6 | 产品详情 | 单根斜 45° 摆放，白底，1600×900 |
| P1 | 施工现场 ×4（开挖敷设、热熔对接、检查井、回填） | 案例详情 | 竖构图更适合手机端 |
| P2 | 车间短视频 15–30s | Hero 背景（可选） | 固定机位，1080p |

**建议**：先拍 P0 六项，用手机 + 三脚架也能出片；P1 白底图可以找本地摄影棚，一天可拍完 6 个系列。

## 四、若继续优化（不加素材也能做的）

1. **滚动进场动效**：区块进入视口时 12px 上移淡入（CSS `animation-timeline` 或 IntersectionObserver），约 20 行代码。
2. **数字滚动**：Hero 数据带、关于页里程碑数字从 0 递增。
3. **产品卡 hover 展开关键参数**：现在只给 DN 区间与前两项等级。
4. **图片懒加载骨架**：拿到实拍图后启用 `next/image` 的 `placeholder="blur"`（需要 base64 缩略图）。
5. **移动端实测**：375 / 414 / 768 三档尚未逐屏核对，规格表在手机端需要横向滚动提示。
6. **Hero 视频/大图轮播**：金纬是轮播，我们目前是静态（更轻、LCP 更好）；若上轮播建议不超过 3 帧。

---

## 五、验收口径

- 首页首屏 LCP < 2.5s（当前无大图，很容易达标；加实拍图后需要压缩到 200KB 内）
- 任意页面滚动时，深/浅底色至少交替一次，不再出现连续 3 段同色
- 每个页面的图位数量 ≥ 2，且占位文案（或实拍图）都在版心内对齐
