# 技术与部署说明

## 一、技术栈

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | Next.js 15.5.29（App Router） | 选 15.5.29 而非 16.x：15.1.x 存在 CVE-2025-66478 弃用告警，15.5.29 为当前维护分支最新补丁版本 |
| 语言 | TypeScript 5.7（strict） | 内容层用类型约束产品/方案/案例字段 |
| 样式 | Tailwind CSS 3.4 + 少量组件类 | 组件类集中在 `src/app/globals.css`（`.btn` `.card` `.tag` `.h1/.h2/.h3` `.spec-table` 等） |
| 导出 | `output: "export"`（纯静态） | 产物在 `Main/out/`，任何静态托管/CDN/对象存储都可部署 |
| 内容 | 文件化（`src/content/*.ts`） | 无数据库、无后台；后续可迁移到 CMS 或 Markdown |
| 表单 | `src/lib/inquiry.ts` → `submitInquiry()` | 无后端也可用；配置 `NEXT_PUBLIC_WECOM_WEBHOOK` 即接企业微信机器人 |

## 三、常用命令

```powershell
# 安装依赖（本机 npm 缓存必须指向工作区，否则 EPERM）
cmd /c "npm install --cache `"E:\1.江西慧洁管业官网项目\.npm-cache`" --registry=https://registry.npmmirror.com"

# 正常机器
npm run dev      # 开发
npm run build    # 静态导出到 out/
npm run start    # npx serve out

# 本机沙箱（禁止 node 派生子进程，必须单进程构建）
node scripts/build-inprocess.cjs build
node scripts/serve-out.cjs 4321   # 预览 out/，访问 http://localhost:4321/
```

> 沙箱限制记录：`spawn EPERM`（errno -4048）来自 node 无法 fork 子进程；Next 的类型检查与静态生成都走 `Worker`。`scripts/build-inprocess.cjs` 通过 `Module._load` 拦截 `next/dist/lib/worker`，将其替换为同进程执行的垫片，构建即可完成。**换到正常服务器/CI 时直接 `npm run build`，无需该脚本。**

## 四、部署方案（建议）

1. 构建：CI 或本地执行 `npm run build`，产出 `out/`。
2. 托管：阿里云 OSS / 腾讯云 COS + CDN，或任意静态空间；Nginx 指向 `out/` 目录。
3. 缓存：`/_next/static/*` 长期缓存（immutable），`*.html` 短缓存（5–10 分钟）。
4. HTTPS 证书 + 强制跳转；备案通过后在页脚填真实 ICP 号（`src/content/site.ts` 的 `site.icp`）。
5. 域名：规划 `https://www.huijiejx.com`，同时把 `site.domain`、`sitemap.ts` 中的域名同步替换。

## 五、询价表单接口契约

前端已按以下契约实现（`InquiryPayload`），后续接后端时无需改 UI：

```
POST /api/inquiry
{
  name, company?, phone, demand: "pipe" | "solution" | "sample" | "other",
  product?, dn?, pn?, quantity?, message?, pageUrl, ts
}
→ 200 { ok: true, id: string }
→ 4xx/5xx { ok: false, error: string }
```

- 无 webhook 时 `submitInquiry()` 进入 demo 模式：控制台打印 payload、600ms 后返回 `{ ok: true }`，便于演示。
- 接入企业微信群机器人：设置环境变量 `NEXT_PUBLIC_WECOM_WEBHOOK`；注意静态站会暴露该地址，建议改为自建轻量接口（云函数）中转，并加简单频率限制。

## 六、SEO 与可访问性

- 每页独立 `metadata`（title/description），详情页用 `generateMetadata` 动态生成，title 模板 `%s | 惠洁管业`。
- 语义结构：每页一个 `h1`，区块用 `section`，图片有 `alt`，表单控件有 `label`。
- `sitemap.xml` 自动生成（静态 11 + 产品 16 + 方案 6 + 案例 6 + 新闻 6）；建议同时提交百度/必应站长平台。
- 后续建议：为产品详情补 `Product` / `BreadcrumbList` JSON-LD 结构化数据；开启 gzip/brotli。

## 七、已知限制

1. 规格表参数由公式推算，`verified: false`，需生产/质检逐项确认。
2. `public/images/wechat-qr.png` 缺失，联系页与页脚为占位框。
3. 案例、新闻为示例内容，页面已标注。
4. 首页与内页暂无实拍图，视觉依赖 CSS 渐变与 SVG 图形；实拍到位后需调整版式留白。
5. 未做多语言；英文站预留 `/en/` 前缀，二期实施。
