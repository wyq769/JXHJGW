## 一、对外披露口径

| 内容 | 是否在官网展示 | 说明 |
| --- | --- | --- |
| 项目名称、项目地点、实施年份 | 展示 | 取自合同"项目名称 / 工程地点 / 签订时间" |
| 产品名称、规格型号、数量 | 展示 | 取自合同"产品名称、规格、数量"清单 |
| 主要管材合计（米/万米） | 展示 | 按合同清单中同类管材长度累加 |
| 其他方（甲方/需方）名称 | 不展示 | 涉及客户商业信息，仅在商务资料中使用 |
| 合同编号、单价、合同金额 | 不展示 | 商业机密，任何页面均不得出现 |
| 现场照片 | 展示 | 我方施工现场实拍；图注只描述工序，不声称拍摄于该项目 |
