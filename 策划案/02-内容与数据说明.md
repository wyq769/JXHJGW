## 二、产品数据结构

```ts
type Product = {
  slug: string;             // URL，如 pe-water-pipe
  name: string;             // PE 给水管（PE100）
  category: string;         // water-supply | drainage | power-telecom | gas | irrigation | sponge-city
  material: string;         // PE100 / PVC-U / HDPE / MPP / PP-R ...
  standard: string;         // GB/T 13663.2-2018
  dnRange: [number, number];
  pressure?: string[];      // 给水类：PN0.6 ~ PN2.5
  stiffness?: string[];     // 结构壁类：SN4 / SN8 / SN12.5 / SN16
  connection: string[];     // 热熔对接 / 电熔连接 / 承插密封
  length: string;           // 直管 6m/9m/12m，盘管 100m/200m
  colorDesc: string;
  summary: string;
  features: string[];
  applications: string[];
  spec: SpecTable;          // 规格表
  verified: boolean;        // 参数是否已由企业核实；当前均为 false
};
```

## 三、规格表生成规则

1. **压力管（PE/PVC-U/PP-R）**：`matrix(dns, pns, density)`
   - 尺寸比：`SDR_PN = { PN0.6:26, PN0.8:21, PN1.0:17, PN1.25:13.6, PN1.6:11, PN2.0:9, PN2.5:7.4 }`
   - 壁厚：`en = dn / SDR`（保留 1 位小数）
   - 理论米重：`π/4 × (d² − di²) × 密度 × 1000`（PE 约 0.95 g/cm³，PVC-U 约 1.4）
   - 列：公称外径 DN / 壁厚 en mm / 尺寸比 / 压力等级 / 理论米重 kg/m（PE/PVC 管公称外径即 DN，不重复列「外径」）
2. **结构壁管（HDPE 双壁波纹、钢带增强螺旋）**：`corrugated(dns, sns)`
   - 外径按 `dn × 1.06` 估算，参考重量按口径与环刚度经验公式
   - 列：公称内径 DN/ID / 内径 mm / 外径 mm / 环刚度 / 参考重量 kg/m
3. **页面免责**：所有规格表底部注明"壁厚按标准尺寸比推算，实际以出厂检测报告为准"，另注明理论米重仅供报价参考。

## 六、文案口径约定

- 公司自称统一为"江西惠洁管业""惠洁管业"，全称"江西惠洁管业科技有限公司"。
- 涉参数处必须带"执行标准 + 参考值"表述，不用"最""第一""唯一"等绝对化用语（广告法风险）。
- 案例与新闻凡属示例内容，页面保留"示例内容，上线前替换"的标注，直到替换为真实内容。
